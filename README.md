# TI Microcontroller Flasher
Embedded development project for programming and interfacing with Texas Instruments microcontrollers, with a focus on firmware flashing, low-level communication, and future expansion toward IoT/CAN-bus applications.

### Repository Structure

* **`TI/`** – Contains the main development files for the **TI TMS320F28379D dual-core microcontroller**, including flashing/programming scripts, bootloader components, and the main application code.

* **`coding_theme/`** – Contains the customization/theme files for **Code Composer Studio (CCS)**, designed to provide a more modern **VS Code-like coding interface and color scheme** for a better development experience.
